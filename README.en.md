## What I work on

- Developing and maintaining 1C configuration extensions.
- Designing HTTP services, REST APIs, and JSON data exchange.
- Integrating 1C with native mobile applications and external systems.
- Working with managed forms, common modules, object modules, and manager modules.
- Designing 1C queries, reports, and Data Composition Schemas.
